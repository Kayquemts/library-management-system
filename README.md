# Library-Management-System
Sistema de Gerenciamento de Biblioteca em linguagem C, utilizando Tipos Abstratos de Dados, Árvore Binária de Busca, fila e lista encadeada. O sistema permite cadastrar livros, buscar livros por código, listar livros em diferentes percursos da árvore, realizar empréstimos, devolver livros, controlar reservas e exibir o histórico de empréstimos.
